# Guides

One task each. They build on the [concepts](../concepts/README.md).

| Guide | You end up with |
|---|---|
| [Load, show and save a scene](load-a-scene.md) | A compose folder on screen, inspected, grafted into, and written back out |
| [Build voxels in code](voxels-in-code.md) | Components filled procedurally: one-offs, continuous grids, streamed terrain |
| [Edit voxels](edit-voxels.md) | A brush: pick under the cursor, add, remove, recolour, undo |
| [Gameplay components](gameplay-components.md) | Your own ECS components, saved in `entities.json` and spawned from it |
| [Add physics](add-physics.md) | Rigid bodies, static colliders, characters and joints from voxels |
| [Write a renderer](write-a-renderer.md) | A renderer folder, from one pass to a G-buffer with accumulation |
| [Logging](logging.md) | The log categories, rate-limited logging, compiling categories out |
| [Testing](testing.md) | The unit suite, the soak, the self-tests, and a test of your own |
